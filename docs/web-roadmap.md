# Web 端里程碑计划

> 状态：2026-11 制定。Web 端（PWA）先行，界面与交互以 [界面与交互设计](design/ui-interaction.md) 和 Figma 设计稿为准。
> 每个阶段拆成若干个小 PR，各自可独立合并、可在线预览（GitHub Pages）。桌面端（Tauri）复用同一套前端，随 Web 端一起推进。

## 总体原则

- **小步合并**：每个 PR 只做一件事，CI（lint / test / build）通过即可合并，主干始终可用。
- **本地优先**：所有阶段数据都只存 IndexedDB；数据库升级用 Dexie 版本迁移，旧数据不丢。
- **逻辑与界面分离**：解析、去重、统计等纯逻辑放在 `src/lib`（不依赖 DOM），带单元测试，将来可抽到 `packages/core` 给小程序和 API 复用。
- **响应式一套代码**：`< 768` 移动布局（底部 Tab），`768–1279` 侧边栏折叠为图标栏，`≥ 1280` 完整桌面布局。
